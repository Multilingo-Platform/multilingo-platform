# Kế hoạch thực thi UC14.4 - Import đề thi từ file

## 1. Scope & Actors
- **Actors**: Admin, Content Creator.
- **Scope**: Chức năng upload file JSON chứa dữ liệu đề thi, parse file, validate, và tái sử dụng service tạo đề thi đã có để lưu toàn bộ.

## 2. Acceptance Criteria (AC)

**AC1: Upload file JSON hợp lệ**
- Given Admin đang ở màn hình danh sách đề thi
- When Admin upload một file JSON có cấu trúc đúng định dạng `ExamBuilderRequest`
- Then hệ thống parse JSON thành công
- And hệ thống tạo mới đề thi với đầy đủ sections và parts
- And hệ thống trả về HTTP 200 kèm ID của đề thi mới

**AC2: Upload file JSON không hợp lệ (cấu trúc sai)**
- Given Admin đang ở màn hình danh sách đề thi
- When Admin upload một file JSON có cấu trúc sai (không map được vào `ExamBuilderRequest`)
- Then hệ thống báo lỗi HTTP 400 "Định dạng file không hợp lệ hoặc lỗi cấu trúc JSON"

**AC3: Upload file JSON hợp lệ nhưng thiếu dữ liệu bắt buộc**
- Given Admin đang ở màn hình danh sách đề thi
- When Admin upload file JSON đúng cấu trúc nhưng thiếu các trường bắt buộc (VD: `title`, `type`)
- Then hệ thống báo lỗi HTTP 422 "Validation error"

## 3. Test Cases (TDD)
- **TC_EXAM_IMPORT_01**: Upload file JSON hợp lệ -> Trả về 200 OK và ID đề thi.
- **TC_EXAM_IMPORT_02**: Upload file text thường (không phải JSON) -> Trả về 400 Bad Request.
- **TC_EXAM_IMPORT_03**: Upload file JSON nhưng rỗng `{}` -> Trả về 422 Unprocessable Entity.

## 4. Kế hoạch triển khai (Task Decomposition)
- **Task 1 (5 phút)**: Tạo `ExamParserService` và method `parseExamJsonFile(MultipartFile file)` trả về `ExamBuilderRequest`. Viết unit test cho service.
- **Task 2 (3 phút)**: Cập nhật `AdminExamController` thêm endpoint `POST /api/admin/exams/import` (nhận `MultipartFile`). Gọi `ExamParserService` sau đó gọi `AdminExamService.createExam()`.
- **Task 3 (5 phút)**: Viết test cho endpoint `POST /api/admin/exams/import` trong `AdminExamControllerTest`.
- **Task 4 (2 phút)**: Chạy toàn bộ test `mvn clean test` để verify.
