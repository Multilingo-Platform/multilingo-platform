# Spec: UC14.4 - Import đề thi từ file

## 1. Mục tiêu
Cho phép Giáo viên/Admin import nhanh toàn bộ đề thi (bao gồm sections và parts) từ một file JSON chuẩn hoặc Excel để tiết kiệm thời gian nhập liệu thủ công.

## 2. Tiền điều kiện
- Người dùng đã đăng nhập và có quyền `ADMIN` hoặc `CONTENT_CREATOR`.
- File import phải tuân thủ định dạng chuẩn (JSON hoặc Excel). Trong phạm vi backend này, ưu tiên hỗ trợ JSON format.

## 3. Luồng sự kiện chính (JSON)
1. Client gửi request `POST /api/admin/exams/import` với `multipart/form-data` chứa tham số `file`.
2. Controller nhận request, chuyển cho `ExamParserService`.
3. `ExamParserService` đọc file JSON, map vào một object trung gian (ví dụ `ExamBuilderRequest`).
4. Validate dữ liệu:
   - File không được rỗng, size hợp lệ.
   - Các trường bắt buộc như `title`, `type` phải có.
   - Ít nhất 1 section, mỗi section ít nhất 1 part.
5. Nếu hợp lệ, chuyển tiếp request sang `AdminExamService.createExam(request)` đã được xây dựng từ trước để tái sử dụng logic lưu.
6. Trả về thông báo thành công và ID của đề thi mới.

## 4. Luồng ngoại lệ
- **File không hợp lệ hoặc lỗi parse JSON**: Báo lỗi `400 Bad Request` với message "Định dạng file không hợp lệ hoặc lỗi cấu trúc JSON".
- **Dữ liệu thiếu/sai logic**: Báo lỗi `422 Unprocessable Entity` (do validator của `createExam`).
- **File quá lớn**: Throw `MaxUploadSizeExceededException`.

## 5. Cấu trúc JSON dự kiến (khớp với ExamBuilderRequest)
```json
{
  "title": "IELTS Mock Test 1",
  "type": "IELTS",
  "examLanguage": "en",
  "isPublished": false,
  "sections": [
    {
      "skillType": "LISTENING",
      "durationMinutes": 40,
      "parts": [
        {
          "partNumber": 1,
          "contentData": {
            // Cấu trúc động tùy chỉnh cho mỗi dạng bài
          }
        }
      ]
    }
  ]
}
```

## 5.1 Cấu trúc Excel dự kiến
- Hỗ trợ file định dạng `.xlsx`.
- Sheet 1: **ExamInfo**
  - Cột A: Tiêu đề (`title`)
  - Cột B: Loại bài thi (`type`)
  - Cột C: Ngôn ngữ (`examLanguage`)
  - Cột D: Đã xuất bản (`isPublished` - TRUE/FALSE)
  - Cột E: Mô tả (`description`)
  - Cột F: Hình ảnh (`thumbnailUrl`)
- Sheet 2: **SectionsAndParts**
  - Cột A: Tên phần thi (`skillType`)
  - Cột B: Thời lượng phút (`durationMinutes`)
  - Cột C: Phần số (`partNumber`)
  - Cột D: Nội dung JSON (`contentData`) - Cột này chứa JSON dạng chuỗi để mô tả contentData của part.

## 6. Giải pháp kỹ thuật Backend
- **Endpoint**: `POST /api/admin/exams/import` (consumes `multipart/form-data`).
- **Service**: 
  - Tạo `ExamParserService` chuyên trách xử lý file. 
  - Interface: `ExamBuilderRequest parseExamJsonFile(MultipartFile file)`.
- **Thư viện**: Sử dụng `ObjectMapper` của Jackson để parse JSON từ chuỗi bytes.
- **Tái sử dụng**: `AdminExamService.createExam(ExamBuilderRequest)` đã có.
