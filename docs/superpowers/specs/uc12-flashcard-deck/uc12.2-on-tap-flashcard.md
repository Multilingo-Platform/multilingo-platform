# Đặc Tả Nghiệp Vụ - UC012.2: Ôn tập Flashcard (SRS)

- **Mã Use Case:** UC012.2
- **Tên Use Case:** Ôn tập Flashcard (Spaced Repetition Flashcard Study)
- **Phân hệ:** Vocab & Flashcards SRS (`com.multilingo.backend.modules.vocab`)
- **Tác nhân (Actor):** Học viên / Người dùng đã đăng nhập hệ thống (`ROLE_USER`)
- **Sự kiện kích hoạt:** Người dùng nhấp chọn nút "Ôn tập Flashcard" từ màn hình chi tiết của một bộ thẻ ghi nhớ hoặc nút "Ôn tập ngay" trên trang danh sách.
- **Tiền điều kiện:** Người dùng đã đăng nhập tài khoản vào hệ thống và bộ thẻ có ít nhất 1 thẻ từ vựng (`total_cards >= 1`).
- **Hậu điều kiện:** Lịch ôn tập tiếp theo (`next_review_date`), độ dễ (`ease_factor`) và khoảng cách ngày (`interval_days`) của từng từ vựng được cập nhật; chuỗi ngày học (streak) và điểm kinh nghiệm (XP) được cộng vào tài khoản người dùng thành công.

## 1. Bảng Đặc Tả Luồng Sự Kiện

### 1.1. Luồng sự kiện chính (Main Success Scenario)

| STT | Thực hiện bởi | Hành động chi tiết |
| :-- | :------------ | :----------------- |
| 1. | Người dùng | Nhấp chọn nút "Ôn tập Flashcard" trên bộ thẻ cần học. |
| 2. | Hệ thống | Kiểm tra tiền điều kiện, tải danh sách các thẻ từ vựng cần ôn tập (các thẻ có `next_review_date <= CURRENT_TIMESTAMP` hoặc toàn bộ thẻ trong bộ) và khởi tạo phiên ôn tập (Study Session). |
| 3. | Hệ thống | Hiển thị mặt trước thẻ (Từ vựng nổi bật, phiên âm IPA, từ loại, nút nghe phát âm và câu ví dụ đã được ẩn từ vựng đích dưới dạng gạch dưới `___`). |
| 4. | Người dùng | Quan sát từ vựng, tự suy nghĩ nghĩa và nhấp vào thẻ (hoặc nhấn phím <kbd>Space</kbd>) để lật mặt sau. |
| 5. | Hệ thống | Lật thẻ 3D hiển thị mặt sau (Định nghĩa đầy đủ bằng ngôn ngữ `sourceLanguage`, câu ví dụ ngữ cảnh hiển thị nguyên vẹn có tô đậm từ vựng) cùng 2 nút đánh giá tự lượng giá: **"Quên"** và **"Đã thuộc"**. |
| 6. | Người dùng | Nhấp chọn 1 trong 2 mức độ tự đánh giá (hoặc bấm phím tắt <kbd>1</kbd>: Quên, <kbd>2</kbd>: Đã thuộc). |
| 7. | Hệ thống | Ghi nhận mức độ nhớ, tính toán thuật toán Spaced Repetition (SRS) để điều chỉnh `ease_factor`, `interval_days`, `review_count` và lên lịch ngày ôn tập tiếp theo (`next_review_date`). |
| 8. | Hệ thống | Chuyển mượt mà sang thẻ tiếp theo trong danh sách phiên học và lặp lại từ bước 3 cho đến khi hoàn thành toàn bộ danh sách thẻ. |
| 9. | Hệ thống | Lưu kết quả học tập vào cơ sở dữ liệu (`user_flashcards` và `daily_study_logs`), cộng điểm kinh nghiệm tích lũy (+10 XP / phiên), cập nhật số lượng thẻ đã ôn trong ngày (`flashcards_reviewed`) và kiểm tra duy trì chuỗi ngày học liên tục (Streak). |
| 10. | Hệ thống | Hiển thị màn hình tổng kết phiên ôn tập (Số thẻ đã hoàn thành, số thẻ thuộc/chưa thuộc, điểm XP đạt được) kèm hiệu ứng vinh danh. |
| 11. | Người dùng | Xem kết quả tổng kết và bấm "Hoàn tất" để quay về màn hình chi tiết bộ thẻ hoặc bấm "Ôn tập lại". |

## 2. Quy Tắc Nghiệp Vụ Thuật Toán Spaced Repetition (SRS Rules)

1. **Trọng số đánh giá (2 mức độ theo đặc tả):**
   - **Đánh giá "Đã thuộc" (Remembered / Good):**
     - Nếu `review_count == 0`: `interval_days = 1` ngày, `status = 'LEARNING'`.
     - Nếu `review_count == 1`: `interval_days = 3` ngày.
     - Nếu `review_count >= 2`: `interval_days = ROUND(interval_days * ease_factor)`.
     - Tăng `review_count += 1`.
     - Nếu `interval_days >= 21`: Chuyển trạng thái thẻ thành `status = 'MASTERED'`.
   - **Đánh giá "Quên" (Forgotten / Again):**
     - `interval_days = 1` ngày (ôn lại vào ngày mai).
     - `ease_factor = MAX(1.30, ease_factor - 0.20)` (giảm độ dễ nhưng không dưới mức sàn 1.30).
     - `status = 'LEARNING'`.
     - Đưa thẻ về cuối phiên học để củng cố phản xạ ghi nhớ ngay lập tức.
2. **Quy định cộng điểm tích lũy & Streak:**
   - Hoàn thành phiên học: Cộng +10 XP vào hồ sơ người dùng.
   - Mỗi thẻ đánh giá "Đã thuộc": Cộng +2 XP.
   - Hệ thống tự động ghi nhận bản ghi vào `daily_study_logs` ngày hôm nay: `flashcards_reviewed += số_thẻ_đã_ôn`. Nếu chưa ghi nhận ngày học hôm nay, cập nhật `study_streak += 1`.

## 3. Thiết Kế API Contracts

### 3.1. Khởi tạo phiên ôn tập Flashcard
- **Endpoint:** `GET /api/v1/vocab/decks/{deckId}/study-session`
- **Mô tả:** Lấy danh sách các thẻ từ vựng ưu tiên tới hạn ôn tập (`next_review_date <= CURRENT_TIMESTAMP`), nếu không có thẻ tới hạn sẽ lấy toàn bộ thẻ trong bộ để người dùng chủ động luyện tập.
- **Response `200 OK`:**
  ```json
  {
    "status": 200,
    "message": "Khởi tạo phiên học thành công",
    "data": {
      "deckId": 1,
      "deckName": "IELTS Academic 3000",
      "targetLanguage": "en",
      "sourceLanguage": "vi",
      "totalSessionCards": 15,
      "cards": [
        {
          "id": 101,
          "customWord": "ubiquitous",
          "phonetic": "/juːˈbɪk.wɪ.təs/",
          "pos": "adj",
          "maskedSentence": "Smartphones have become _______ in daily modern life.",
          "customMeaning": "có mặt ở khắp mọi nơi",
          "fullSentence": "Smartphones have become ubiquitous in daily modern life.",
          "customImageUrl": "https://...",
          "reviewCount": 2,
          "status": "LEARNING"
        }
      ]
    }
  }
  ```

### 3.2. Gửi đánh giá SRS cho từng thẻ
- **Endpoint:** `POST /api/v1/vocab/cards/{cardId}/review`
- **Request Body:**
  ```json
  {
    "rating": "REMEMBERED" // Hoặc "FORGOTTEN"
  }
  ```
- **Response `200 OK`:**
  ```json
  {
    "status": 200,
    "message": "Ghi nhận đánh giá SRS thành công",
    "data": {
      "cardId": 101,
      "status": "LEARNING",
      "reviewCount": 3,
      "intervalDays": 7,
      "easeFactor": 2.50,
      "nextReviewDate": "2026-10-10T23:30:00"
    }
  }
  ```

### 3.3. Hoàn tất và lưu kết quả phiên học
- **Endpoint:** `POST /api/v1/vocab/decks/{deckId}/finish-session`
- **Request Body:**
  ```json
  {
    "cardsReviewed": 15,
    "cardsRemembered": 12,
    "cardsForgotten": 3,
    "durationSeconds": 180
  }
  ```
- **Response `200 OK`:**
  ```json
  {
    "status": 200,
    "message": "Lưu kết quả phiên học thành công",
    "data": {
      "earnedXp": 34,
      "currentStreak": 6,
      "totalMasteredCards": 8
    }
  }
  ```
